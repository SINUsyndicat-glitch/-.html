# SINU Syndicate - World Cup 2026 Prediction dApp

Welcome to the official prediction platform for the 2026 World Cup, built on the **Base** blockchain. SINU Syndicate allows users to predict match outcomes and earn rewards in a fully decentralized and transparent way.

## 🚀 Key Features

* **Decentralized Predictions:** All predictions are recorded on-chain, ensuring 100% transparency.
* **Deflationary Model:** 10% of the total prize pool is automatically burned with every match resolution to support the $SINU token economy.
* **Fair Distribution:** Rewards are automatically distributed to all winners proportional to their entry.
* **Admin-Controlled Resolutions:** Secure result submission managed by the contract owner.

## 🛠 Tech Stack

* **Blockchain:** Base (Ethereum L2)
* **Smart Contract:** Solidity (0.8.26)
* **Frontend:** HTML, JavaScript, Ethers.js
* **Deployment:** Vercel

## 📜 How it Works

1. **Create Match:** Admin creates a match event on the blockchain.
2. **Place Prediction:** Users connect their wallets and pay the entry fee in $SINU to place their prediction (Team 1, Team 2, or Draw).
3. **Resolve:** After the match, the admin submits the result. The contract then:
   - Burns 10% of the pool.
   - Distributes the remaining 90% equally among the winners.
